# รัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๖๐ — ฉบับอ่านง่าย

เว็บไซต์หน้าเดียวสำหรับอ่านตัวบทรัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๖๐
ฉบับปรับปรุงล่าสุด (รวมการแก้ไขเพิ่มเติมทุกฉบับที่ประกาศใช้แล้ว) พร้อมสารบัญ ค้นหา
ลิงก์โยงมาตรา เทียบถ้อยคำก่อน/หลังแก้ไข อภิธานศัพท์ และหน้าพิมพ์/PDF

> เว็บไซต์ไม่เป็นทางการ จัดทำเพื่อการศึกษา — การอ้างอิงทางกฎหมายโปรดตรวจกับราชกิจจานุเบกษา

## ที่มาของตัวบท

| ชุด | แหล่ง |
|---|---|
| ฉบับปรับปรุงล่าสุด, ฉบับหลัก, ฉบับแก้ไขเพิ่มเติม (ฉบับที่ ๑) พ.ศ. ๒๕๖๔ | ระบบฐานข้อมูลกฎหมาย สำนักงานคณะกรรมการกฤษฎีกา (searchlaw.ocs.go.th) ดึงเมื่อ 2026-09-24 → `data/source-ocs/` |
| ฉบับหลัก ๒๕๖๐ (ใช้ตรวจเทียบ) | ราชกิจจานุเบกษา เล่ม ๑๓๔ ตอนที่ ๔๐ ก หน้า ๑ วันที่ ๖ เมษายน ๒๕๖๐ → `sources/gazette/` |

รัฐธรรมนูญและกฎหมายไม่ถือเป็นงานอันมีลิขสิทธิ์ตามพระราชบัญญัติลิขสิทธิ์ พ.ศ. ๒๕๓๗ มาตรา ๗ (๒)

## ขั้นตอนสร้างเว็บ

```bash
node tools/scrape_ocs.mjs VG9mbS9RRXZhdjNGYy9Xcm5LTjd1Zz09 data/source-ocs-new   # ดึงใหม่จากกฤษฎีกา (headless Chrome)
python tools/parse_ocs.py        # data/source-ocs/*.json → data/constitution.json (+ ตรวจความสอดคล้อง)
python tools/verify_gazette.py   # ฉบับหลักเทียบ PDF ราชกิจจานุเบกษา ทีละตัวอักษร
python tools/build.py            # → index.html
python tools/verify_site.py      # อ่าน index.html กลับมาเทียบกับข้อมูลดิบของกฤษฎีกา
```

`parse_ocs.py` หยุดทันทีถ้า: เลขมาตราไม่ครบ ๑–๒๗๙, มาตราที่ต่างกันระหว่างฉบับหลักกับฉบับปรับปรุง
ไม่ตรงกับที่ฉบับแก้ไขระบุ, หรือถ้อยคำใหม่ในฉบับแก้ไขไม่ตรงกับฉบับปรับปรุงทุกตัวอักษร

## ตัวบททางการ กับ คำอธิบาย

- ข้อความในกรอบมาตรา คำปรารภ และตัวบทฉบับแก้ไข — คัดลอกจากแหล่งโดยไม่แก้ถ้อยคำ
- กล่องเส้นประ (`.rc-explain`), อภิธานศัพท์ (`data/glossary.json`) และไฮไลต์ความต่าง — เขียน/คำนวณโดยผู้จัดทำ ไม่ใช่ตัวบท
